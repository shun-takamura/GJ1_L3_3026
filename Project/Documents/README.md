# ArcanaEngine リファレンス

使い方の逆引き。各ページは **最小の動くコード片 ＋ 注意点** の形式で書いてある。

まず [01_GettingStarted.md](01_GettingStarted.md) を読み、動かなくなったら [12_Pitfalls.md](12_Pitfalls.md) を見る、という使い方を想定している。

| | ページ | 内容 |
|---|---|---|
| 01 | [はじめに](01_GettingStarted.md) | アプリの組み立て方。`Framework` / `Scene` / `ISceneRunner` の3点セットとフック配線 |
| 02 | [描画](02_Rendering.md) | モデル / アニメーション / スプライト / プリミティブ / カメラ / ライト / 描画順 |
| 03 | [アセット](03_Assets.md) | `Assets/` → `Resources/` のパイプライン。素材の追加手順 |
| 04 | [シェーダ](04_Shaders.md) | 追加方法・命名規則・`.cso` 事前コンパイル |
| 05 | [入力](05_Input.md) | アクションマップ・キーボード / マウス / ゲームパッド・リプレイ |
| 06 | [当たり判定](06_Collision.md) | `Collider` / `CollisionSystem` / レイヤーのフック注入 |
| 07 | [エフェクト](07_Effects.md) | Effect Editor の全項目とコードからの再生 |
| 08 | [サウンド](08_Audio.md) | 2D / 3D 再生 |
| 09 | [ポストエフェクト](09_PostEffect.md) | 13種のフィルタと適用順 |
| 10 | [エディタ](10_Editor.md) | 各ウィンドウ・ホストフック・エディタの拡張 |
| 11 | [ユーティリティ](11_Utilities.md) | 時間 / テキスト / デバッグ描画 / JSON / 数学 / 乱数 / ログ / プロファイラ |
| 12 | [落とし穴集](12_Pitfalls.md) | **うまくいかないときに最初に見る** |
| 13 | [アイコンとタイトル](13_AppIcon.md) | ウィンドウタイトル・exe アイコンの変え方 |
